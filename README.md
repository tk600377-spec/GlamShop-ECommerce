GLAMNEST SHOP - DEPLOY ON NETLIFY
=================================
Files: index.html, style.css, app.js, shop-data.json

FIRST TIME
 1. Go to https://app.netlify.com/drop  (sign up / log in free).
 2. Drag this whole folder (glamnest-site) onto the page.
 3. Netlify gives you a link like https://something.netlify.app  -> put it in your Instagram bio.
    (Site settings > Change site name to make it nicer; Domain management to add your own domain.)

ADMIN
 Tap the logo 5 times (or add #admin to the link). Username: admin  Password: admin@098
 Change the password in Admin > Users.

UPDATING PRODUCTS / PRICES / SETTINGS FOR ALL CUSTOMERS
 1. Make your edits in Admin.
 2. Press "Download shop-data.json".
 3. In Netlify: Site > Deploys > drag the folder again (with the new shop-data.json replacing the old one).
    Customers see the update within a minute.

SALES / PURCHASE / WASTAGE / VISITOR ENTRIES
 Stored in the browser you use for admin (not uploaded). Download the Excel report regularly as backup.
 Use one device for entries.
